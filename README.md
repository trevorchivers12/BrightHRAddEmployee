# BrightHRAddEmployee
Technical task to add employee to Bright HR

- Fixtures added to login and Delete Employees
- PageObjects added for functions and variables
- commonUtils - custom functions added so able to reuse through the pageobjects and tests
- taerDownHelper added to remove employees after adding to the employees hub
- GitHub workflow added

Covers the following steps:

1. Navigate to the employee tab on the left-hand side of the panel and add an employee by filling in all the fields, including optional ones.

2. Add another employee.

3. Navigate to the employee tab and verify that both employees are displayed.

4. Runs on CI via github on every PR created
